# Festival editor decisions

- **Session formats.** Switching variants discards the outgoing branch’s fields. Returning to a workshop starts with empty workshop materials.
- **Lost save acknowledgement.** Keep the draft and read the saved version. Matching content confirms the submitted value. An unchanged base permits a retry. If verification is offline, the next check reads again. A different saved revision and value requires reconciliation.
- **Renaming an entity (recommendation).** Let people edit display names freely. Keep the identity used by references stable once the entity is saved. An editable human-facing code can be a separate attribute if a workflow needs one. The festival demo currently allows coordinated ID and reference edits in one program save; changing that behavior is an open decision.
